# Introduction <a name="introduction"></a>
The API is used to get health details of a load balancing rule from Azure API Server (https://management.azure.com/). The response includes the details like up, down and loadBalancerBackendAddresses.



The original Azure RESTful API used is <Load Balancer Load Balancing Rules - Health>. 



For a complete list of available API resources for Azure Load Balancer, please refer to Microsoft document: [Load Balancers - REST API (Azure Load balancer) | Microsoft Learn](https://learn.microsoft.com/en-us/rest/api/load-balancer/load-balancers?view=rest-load-balancer-2024-03-01)

For the original Azure API detailed information, please refer to Microsoft document: [Load Balancer Load Balancing Rules - Health - REST API (Azure Load balancer) | Microsoft Learn](https://learn.microsoft.com/en-us/rest/api/load-balancer/load-balancer-load-balancing-rules/health?view=rest-load-balancer-2025-07-01&viewFallbackFrom=rest-load-balancer-2025-05-01&tabs=HTTP)
