# Introduction <a name="introduction"></a>
The API is used to get all routes in a route table from Azure API Server (https://management.azure.com/). The response includes the details like name, provisioningState, addressPrefix, nextHopType, etc.



The original Azure RESTful API used is <Routes - List>.



For a complete list of available API resources for Azure Routes, please refer to Microsoft document: https://learn.microsoft.com/en-us/rest/api/virtualnetwork/routes?view=rest-virtualnetwork-2023-09-01

For the original Azure API detailed information, please refer to Microsoft document: https://learn.microsoft.com/en-us/rest/api/virtualnetwork/routes/list?view=rest-virtualnetwork-2023-09-01&tabs=HTTP
