# Introduction <a name="introduction"></a>
The API is used to retrieve the details of all RouteTables from Azure API Server (https://management.azure.com/). The response includes the details like id, name, type and properties.



The original Azure RESTful API used is <Hub Route Tables - List>. 



For a complete list of available API resources for Azure Virtual Hub, please refer to Microsoft document: [Virtual Network Gateways - REST API (Azure Network Gateway) | Microsoft Learn](https://learn.microsoft.com/en-us/rest/api/network-gateway/virtual-network-gateways?view=rest-network-gateway-2025-07-01&viewFallbackFrom=rest-network-gateway-2023-09-01)

For the original Azure API detailed information, please refer to Microsoft document: [Hub Route Tables - List - REST API (Azure Virtual WAN) | Microsoft Learn](https://learn.microsoft.com/sk-sk/rest/api/virtualwan/hub-route-tables/list?view=rest-virtualwan-2025-07-01&viewFallbackFrom=rest-virtualwan-2025-05-01&tabs=HTTP)
