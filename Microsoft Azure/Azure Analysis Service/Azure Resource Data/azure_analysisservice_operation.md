# Introduction <a name="introduction"></a>
The API is used to lists all of the available consumption REST API operations from Azure API Server (https://management.azure.com/). The response includes the details like name, display and origin.



The original Azure RESTful API used is <Operations - List>. 



For a complete list of available API resources for Azure Analysis Service, please refer to Microsoft document: [Operations - REST API (Azure Analysis Services) | Microsoft Learn](https://learn.microsoft.com/en-us/rest/api/analysisservices/operations?view=rest-analysisservices-2017-08-01)

For the original Azure API detailed information, please refer to Microsoft document: [Operations - List - REST API (Azure Analysis Services) | Microsoft Learn](https://learn.microsoft.com/en-us/rest/api/analysisservices/operations/list?view=rest-analysisservices-2017-08-01)
