# Introduction <a name="introduction"></a>
The API is used to get details about the specified Analysis Services server resource information from Azure API Server (https://management.azure.com/). The response includes the details like name, id, location and properties.



The original Azure RESTful API used is <Servers - Get Details>. 



For a complete list of available API resources for Azure Analysis Service, please refer to Microsoft document: [Servers - REST API (Azure Analysis Services) | Microsoft Learn](https://learn.microsoft.com/en-us/rest/api/analysisservices/servers?view=rest-analysisservices-2017-08-01)

For the original Azure API detailed information, please refer to Microsoft document: [Servers - Get Details - REST API (Azure Analysis Services) | Microsoft Learn](https://learn.microsoft.com/en-us/rest/api/analysisservices/servers/get-details?view=rest-analysisservices-2017-08-01&tabs=HTTP)
