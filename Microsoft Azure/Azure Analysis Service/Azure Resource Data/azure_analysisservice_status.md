# Introduction <a name="introduction"></a>
The API is used to return the gateway status of the specified Analysis Services server instance from Azure API Server (https://management.azure.com/). The response includes the details like status.



The original Azure RESTful API used is <Servers - List Gateway Status>. 



For a complete list of available API resources for Azure Analysis Service, please refer to Microsoft document: [Servers - REST API (Azure Analysis Services) | Microsoft Learn](https://learn.microsoft.com/en-us/rest/api/analysisservices/servers?view=rest-analysisservices-2017-08-01)

For the original Azure API detailed information, please refer to Microsoft document: [Servers - List Gateway Status - REST API (Azure Analysis Services) | Microsoft Learn](https://learn.microsoft.com/en-us/rest/api/analysisservices/servers/list-gateway-status?view=rest-analysisservices-2017-08-01&tabs=HTTP)
