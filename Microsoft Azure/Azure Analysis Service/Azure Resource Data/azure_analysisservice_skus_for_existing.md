# Introduction <a name="introduction"></a>
The API is used to lists eligible SKUs for an Analysis Services resource from Azure API Server (https://management.azure.com/). The response includes the details like name and tier.



The original Azure RESTful API used is <Servers - List Skus For Existing>. 



For a complete list of available API resources for Azure Analysis Service, please refer to Microsoft document: [Servers - REST API (Azure Analysis Services) | Microsoft Learn](https://learn.microsoft.com/en-us/rest/api/analysisservices/servers?view=rest-analysisservices-2017-08-01)

For the original Azure API detailed information, please refer to Microsoft document: [Servers - List Skus For Existing - REST API (Azure Analysis Services) | Microsoft Learn](https://learn.microsoft.com/en-us/rest/api/analysisservices/servers/list-skus-for-existing?view=rest-analysisservices-2017-08-01&tabs=HTTP)
